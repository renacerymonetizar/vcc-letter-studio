1. Bienvenida al dashboard

Esta es la portada visual de Visual Letter Studio™. Desde aquí las alumnas entienden hacia dónde van antes de empezar a construir sus prompts dentro del Studio.

Qué van a encontrar aquí

Visual Letter Studio™ es un laboratorio interactivo de letras temáticas. Aquí no trabajan desde una plantilla cerrada: exploran opciones, combinan estilos y construyen un prompt profesional paso a paso.

La alumna puede crear desde cero o usar una foto base para añadirle letras temáticas y composición visual.

Cómo usarlo

  • Regístrate para entrar al Studio.
  • Elige tu modo de creación: desde cero o usando una foto.
  • Explora la biblioteca creativa de temáticas, materiales, mundos visuales, luces y acabados.
  • Genera tu prompt y llévalo a ChatGPT para crear la imagen.

2. Elige tu modo de creación

Antes de construir el prompt, la alumna decide si quiere crear toda la imagen desde cero o si va a usar una foto como base para añadirle las letras temáticas.

Selecciona cómo vas a trabajar

CREAR DESDE CERO

Construir toda la imagen

Ideal si quieres que ChatGPT genere toda la escena completa: el universo visual, las letras, la composición y el ambiente desde cero.

USAR UNA FOTO

Trabajar sobre una imagen base

Ideal si ya tienes una foto y quieres agregarle lettering temático. El prompt final te recordará que debes subir la imagen junto con el prompt en ChatGPT.

Modo actual: Crear desde cero. El Studio construirá un prompt para generar toda la pieza completa.

Qué cambia según la opción

  • Crear desde cero: solo necesitarás copiar el prompt final y llevarlo a ChatGPT.
  • Usar una foto: además del prompt final, tendrás que subir la imagen que quieres usar como base.
  • Ambas opciones usan la misma biblioteca de temáticas, materiales, luces, composición y estilo.
Esto les da claridad a las muchachas desde el principio: pueden entrar a crear una imagen completa o mejorar una foto que ya tengan.

3. Intención

Primero defines qué debe hacer sentir la pieza. Una letra temática no empieza por el material: empieza por la emoción y por el propósito.

Qué aprendes aquí

La tipografía temática convierte el texto en un objeto visual con personalidad, materia, profundidad y narrativa. La palabra no solo se lee: también se siente.

Regla VCC: primero intención, después estética.

5. Materialidad de las letras

Selecciona o inventa la materia. La biblioteca te ayuda, pero también puedes crear combinaciones propias.

Materia + textura + comportamiento

No basta con decir “oro” o “vidrio”. Una buena dirección visual también define acabado, textura y cómo se comporta el material frente a la luz.

La alumna puede usar la biblioteca o crear un material totalmente nuevo.

6. Composición y encuadre

Aquí se decide dónde viven las letras dentro de la imagen y cómo conviven con el sujeto o el producto.

Protección de la composición

Si hay una persona o producto, las letras no deben arruinar la jerarquía visual. Por eso este paso es tan importante.

Usa espacio negativo y protege rostro, cuerpo o producto cuando haga falta.
