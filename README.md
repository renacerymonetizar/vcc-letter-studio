# Visual Letter Studio™

Laboratorio interactivo de letras temáticas de Visual Creator Club.

Proyecto preparado para GitHub → Netlify con:
- registro e inicio de sesión por Netlify Identity,
- recuperación de contraseña por correo,
- biblioteca creativa de temáticas, materiales, composición e iluminación,
- generación de prompt maestro para llevar a ChatGPT.

## Despliegue en Netlify
1. Importa este repositorio en Netlify.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Activa Identity en Project configuration → Identity.
5. Deja Registration en Open si quieres que las alumnas se registren solas.
